# Insided Custom Widget Gainsight

Example implementation of a custom widget based on the Insided widget schema.

## Features

- Configurable widget settings
- Adjustable widget dimensions
- iframe-based widget rendering
- modular structure

## Run locally

npm install
npm start

## Structure

src/widget.json -> widget schema
src/index.js -> widget logic
src/styles.css -> styles
public/index.html -> widget preview
